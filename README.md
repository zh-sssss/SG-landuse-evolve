# SG Land Use Evolve

**Live website:** [https://zh-sssss.github.io/SG-landuse-evolve/](https://zh-sssss.github.io/SG-landuse-evolve/)

An interactive story examining how Singapore's planned land use evolved from 2003 to 2025 and how selected street environments changed over time.

The project compares the 2003, 2014 and 2025 Master Plans using a 500 m grid. Areas in the top 15% of 2003–2025 land-use change are used to select three qualitative cases for comparison with historical Google Street View imagery.

Data sources: URA Master Plan Land Use datasets via data.gov.sg and manually captured Google Street View images.
